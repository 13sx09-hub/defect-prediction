# 비만 위험군 선별 프로젝트 (day06/project_v1)

문진(설문) 응답만으로, 비만이 될 위험이 큰 사람을 검사 전에 미리 가려내는 프로젝트입니다.

## 1. 왜 이 문제인가

- **누가 쓰나**: 보건소나 1차 진료에서 일하는 영양 상담사
- **무엇을 결정하나**: 문진 응답을 바탕으로, 이 사람을 비만 위험군으로 보고 영양 상담을 먼저 권할지 말지
- **언제 결정하나**: 체성분 검사 같은 정밀 검사를 받기 전, 문진 응답을 받은 직후

이 판단이 늦으면 비만 단계를 늦게 알게 되어 식단·운동 개입 시작이 늦어지고, 과체중을 지나 고도비만까지 진행될 수 있습니다. 원래는 정밀 검사를 받아야 알 수 있는 걸, 검사 전 문진 단계에서 미리 짐작할 수 있게 해주는 게 이 프로젝트의 목적입니다.

## 2. 데이터

- **출처**: UCI Machine Learning Repository - "Estimation of obesity levels based on eating habits and physical condition" (Kaggle에도 같은 데이터가 올라와 있습니다)
- **원본 규모**: 2111행 x 17열
- **정제**: 완전히 같은 값이 두 번 이상 들어간 중복행 24건을 제거해서 **2087행 x 17열**로 정리했습니다. 빈칸이 많은 열이나 값이 하나로 고정된 열은 없어서 열 개수는 그대로입니다.
- **결과 열(맞혀야 하는 것)**: `NObeyesdad` (비만 단계, 7종: 저체중~고도비만 3단계). 이 프로젝트에서는 `Obesity_Type_I/II/III`(비만)이면 1, 나머지 4종(저체중·정상·과체중 2단계)이면 0으로 둘로 나눠서(이진화) 썼습니다. 전체 2087건 중 비만은 972건(46.6%)입니다.
- **입력으로 쓴 열 (6개)**: 원래 8개의 숫자 열 중 아래 6개만 씁니다.
  - `Age` (나이)
  - `FCVC` (채소를 얼마나 자주 먹는지)
  - `NCP` (하루에 주식을 몇 끼 먹는지)
  - `CH2O` (하루 물 섭취량)
  - `FAF` (운동을 얼마나 자주 하는지)
  - `TUE` (전자기기 사용 시간)
- **뺀 열 (2개, 이유 있음)**: `Height`(키), `Weight`(몸무게)는 뺐습니다. 이 둘로 BMI(몸무게÷키²)를 계산해보면 `NObeyesdad` 클래스 범위와 거의 겹치지 않을 만큼 딱 맞아떨어집니다 — 즉 결과 열을 다른 모양(키·몸무게)으로 숨겨놓은 것에 가깝습니다. 그대로 넣으면 모델이 진짜 생활습관을 배우는 게 아니라 BMI 계산기처럼 동작하게 되고, "정밀 검사 전에 미리 가려낸다"는 목적과도 어긋나서 뺐습니다.

## 3. 무엇을 했나

1. **정제**: 중복행 24건 제거
2. **변수 선택**: 위에서 설명한 이유로 `Height`, `Weight` 제외, 숫자 열 6개만 입력으로 사용
3. **빈칸 채우기**: 입력 열에 빈칸이 있으면 그 열의 중앙값으로 채우도록 준비했으나, 실제로는 빈칸이 없었습니다
4. **학습·시험 나누기**: 8:2로 나누고, 비만 비율(46.6%)이 양쪽에 똑같이 가도록 맞췄습니다 (학습 1669건, 시험 418건)
5. **모델**: 값을 같은 단위로 맞추는 표준화를 한 뒤, 로지스틱 회귀(분류 모델)를 학습시켰습니다. 기본 버전과, 드문 쪽(비만)에 더 무게를 두는 `class_weight="balanced"` 버전 두 가지를 만들었습니다
6. **검증**: 혼동행렬(실제값 × 예측값을 4칸으로 나눠 세는 표)로 결과를 확인했습니다

## 4. 결과 수치

**기준 모델**(아무것도 배우지 않고 무조건 "비만 아님"이라고만 답하는 비교용 모델)의 정확도는 53.35%였습니다. 실제로 학습시킨 모델(v1)의 정확도는 65.55%로, 12.20%p 올랐습니다.

시험용 418건을 혼동행렬로 나누면 이렇습니다.

| | 예측: 비만 아님 | 예측: 비만 | 실제 합계 |
|---|---|---|---|
| **실제: 비만 아님** | 163건 (맞음) | 60건 (헛지목) | 223건 |
| **실제: 비만** | 84건 (놓침) | 111건 (제대로 잡음) | 195건 |

- **정밀도**(모델이 "비만"이라고 지목한 것 중 진짜였던 비율): 111/171 = **0.649**
- **재현율**(실제 비만인 사람 중 모델이 잡아낸 비율): 111/195 = **0.569**

즉 모델이 "비만"이라고 지목한 171명 중 60명(35%)은 틀린 지목이고, 실제 비만 195명 중 84명(43%)은 놓쳤습니다. 정확도만 보면 나아 보이지만, 재현율이 낮아서 "위험군을 미리 가려낸다"는 원래 목적에는 아직 부족합니다.

### class_weight="balanced" 버전과 비교

| | 지목 건수 | 그중 진짜 | 재현율 | 정밀도 |
|---|---|---|---|---|
| 기본 모델 | 171건 | 111건 | 0.569 | 0.649 |
| 가중치 모델 | 197건 | 122건 | 0.626 | 0.619 |

가중치를 준 모델은 더 많이 지목해서(171→197건) 놓치는 사람은 줄었지만(84명→73명), 대신 헛지목은 늘었습니다(60건→75건). 즉 "놓치는 걸 줄이는 대신 헛지목을 좀 더 감수하는" 방향입니다.

## 6. 그래서 무엇을 하자는 것인가

모델이 비만 가능성이 높다고 지목한 사람은, 정밀 검사(체성분 검사 등)로 넘기기 전에 영양 상담 대상으로 먼저 불러들이자는 것입니다. 다만 지금 v1(기본 모델)로는 실제 비만 195건 중 111건만 걸러지므로, 이 상태로 현장에 바로 거는 것은 이릅니다.

## 7. 한계

- `Age`, `FCVC`, `NCP`, `CH2O`, `FAF`, `TUE`에 정수가 아닌 값이 섞여 있습니다. 원 데이터 문서에 따르면 응답의 상당수가 SMOTE 같은 방법으로 합성됐다고 하며, 이 흔적으로 보입니다 — 즉 실제 사람의 응답 그대로가 아닐 수 있습니다
- 설문을 한 시점에 한 번에 걷은 데이터라, 계절이나 나이가 들면서 습관이 바뀌는 긴 흐름은 담겨 있지 않습니다
- 표본은 콜롬비아·페루·멕시코 응답자를 대상으로 한 설문이라, 다른 나라·다른 시기 사람에게 그대로 적용하기는 어렵습니다
- 특정 습관(예: 고칼로리 음식 섭취)에서 비만 단계가 높게 관찰되더라도, 습관과 비만 단계가 같은 시점에 함께 걷힌 것이라 그것이 원인이라고는 말할 수 없습니다
